## 🎮 GameZone - Sitio Web de Videojuegos
Proyecto web desarrollado para la materia de Programación Web, demostrando el uso de React con Vite, componentes reutilizables y múltiples funcionalidades interactivas.

## 📋 Características
# 🎯 Páginas
Inicio	    Landin page con presentación y cards de características
Nosotros	Información del equipo y misión del proyecto
Servicios	Servicios ofrecidos con precios y botones interactivos
Galería	    Catálogo de 6 videojuegos con sistema de búsqueda y filtros
Contacto	Formulario de contacto con validación y mensaje de éxito

## 🎮 Funcionalidades
# 🔍 Sistema de Búsqueda y Filtros
Búsqueda por nombre de videojuego
Filtrado por categoría (Aventura, RPG, Deportes, Shooter, Sandbox, Battle Royale)
Mensaje dinámico cuando no hay resultados

## 📱 Menú Responsive
Botón hamburguesa para dispositivos móviles
Navegación intuitiva con React Router
Enlaces activos con estilo diferenciado

## ✅ Validación de Formularios
# Validación de campos requeridos (nombre, email, mensaje)
Validación básica de email
Mensaje de éxito dinámico al enviar

## 🃏 Componentes Interactivos
# Tarjetas con hover effect (transform y sombra)
Botones con variantes (primario, secundario)
Alertas dinámicas de éxito/error

## 🛠️ Tecnologías Utilizadas
React	
Vite	
React Router DOM	
CSS3	
JavaScript (ES6+)	

## Características técnicas:
✅ Componentes reutilizables con props
✅ useState para manejo de estado
✅ Filtrado dinámico con .filter() e .includes()
✅ CSS Modules por componente
✅ Diseño responsive con Media Queries

## 📸 Galería de Videojuegos
# La galería incluye 6 videojuegos con:
Nombre del juego
Imagen representativa
Descripción corta
Precio
Categoría
Botón "Ver más" interactivo

## Funcionalidades de la galería:
🔍 Búsqueda por nombre (insensible a mayúsculas)
🏷️ Filtrado por categoría
📱 Diseño responsive en grid
💬 Mensaje "No se encontraron juegos" cuando no hay resultados

## Como ejecutarlo
# 1. Clonar el repositorio
git clone 

# 2. Entrar a la carpeta del proyecto
cd vite-project

# 3. Instalar dependencias
npm install

# 4. Instalar React Router DOM
npm install react-router-dom

# 5. Iniciar el servidor de desarrollo
npm run dev

# 6. Abrir el navegador en
http://localhost:5173
